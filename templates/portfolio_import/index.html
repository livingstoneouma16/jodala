Bulk Loan Import

Migrate an existing loan portfolio in from a CSV export of your previous system

1. Upload CSV

Each row is one loan. Required columns: product_code, principal_amount, interest_rate, interest_type, term, repayment_frequency, disbursement_date, first_repayment_date. Identify the borrower with member_number or client_number if they're already registered, or with first_name, last_name, phone to create a new client record automatically. To bring in a loan that's already partly paid, add installments_paid (marks that many installments paid in order) and optionally total_paid if the exact amount differs from a clean per-installment split.
